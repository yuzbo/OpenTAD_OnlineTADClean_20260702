# Hierarchical Event Memory 2025

## One-line thesis

Online video temporal grounding can localize query-related event starts and ends using event proposals, hierarchical memory, and an optional future-prediction branch for latency.

## Relevance to This Project

Although query-conditioned grounding differs from closed-set On-TAL, this paper blocks broad claims around event-level memory, low-latency start/end prediction, or event proposal maintenance in streaming video.

# OpenHOUSE 2025

## One-line thesis

Hierarchical streaming video understanding combines online temporal action localization with immediate free-form descriptions of atomic actions and higher-level events.

## Method

OpenHOUSE uses a specialized streaming boundary module and a VLM-oriented hierarchical event description pipeline.

## Relevance to This Project

This paper blocks a broad claim that combining Online TAD with streaming semantic maintenance or hierarchical event understanding is unexplored. Our defensible scope must remain identity-linked temporal action instances, belief revision, and irreversible commit under detection metrics.

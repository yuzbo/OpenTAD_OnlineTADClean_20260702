## 研究目标

目标是标准、封闭类别、全监督、严格因果的在线时序动作定位。模型在当前时刻只能使用已经观察到的特征、过去状态和当前真实可观察的流结束信号；不得使用真实视频总长、完整视频时间比例、离线结束信息、未来帧或推理时真实标注。

核心假设不是单独宣称“删失风险”“轨迹查询”或“循环展开”新颖，而是检验以下部件能否组成一个必要且可审计的在线事件生命周期：

1. 稳定的出生前时序分配；
2. 事件归一化、区间删失的首次出生风险；
3. 右删失的终点风险；
4. 训练与推理一致的按时间顺序动态事件展开；
5. 出生后身份锁定；
6. 显式取消与重新获取；
7. 不可变、正长度、无重复、无静默容量淘汰的事件账本。

## 已核验事实

- D0 已证明网络不是梯度死亡，但出生和终点正样本约占 `0.1477%`，旧版固定归属生命周期没有闭合。
- 当前五轮训练的所有损失有限并下降；执行与完整性检查通过。
- 原生父模型在训练前缀诊断中产生 `21,256` 个提案，覆盖 `176/200` 个训练视频。
- 运行时对齐组和身份轨迹组在第五轮的训练前缀诊断中均为零输出。
- 删失风险组产生 `333` 个提案，覆盖 `47/200` 个视频；完整组合组产生 `271` 个提案，覆盖 `42/200` 个视频。
- 上述训练前缀指标不是论文结果，因为训练状态、教师轨迹和完整训练集诊断不能代表严格推理泛化。

随后对同一批五轮权重进行了评估模式、预测轨迹专用、全训练集顺序重放。四组均处理 `203,363` 个真实前缀和 `200` 个实际观察到的结束标记；测试集未访问，权重未更新，出生和终点没有数值阈值，也没有阈值搜索。

严格重放的关键结果：

| 组别 | 出生 | 取消 | 终点/写出 | 重新获取 | 实际结束时仍活动 | 有提案视频 |
|---|---:|---:|---:|---:|---:|---:|
| 运行时对齐 | 46,935 | 46,892 | 0 / 0 | 0 | 43 | 0 / 200 |
| 身份轨迹 | 5,670 | 5,667 | 0 / 0 | 4,017 | 3 | 0 / 200 |
| 删失风险 | 2,648 | 2,599 | 46 / 46 | 0 | 3 | 6 / 200 |
| 完整组合 | 5,621 | 5,072 | 519 / 519 | 3,611 | 30 | 26 / 200 |

补充事实：

- 前两组有大量出生，因此零输出不是“没有候选起点”。
- 前两组的归属终点胜出次数均为零，取消率分别为 `99.908%` 和 `99.947%`。
- 后两组每次终点都逐条写入账本，因此写出器不是瓶颈。
- 后两组在时间重叠 `0.3` 下的召回率仅为 `0.166%` 和 `0.998%`。
- 后两组只有 `2/6` 个真实终点前缀出现任意归属终点胜出；这还是没有身份核对的上限。
- 身份轨迹组和完整组合组有大量“取消—重新获取”循环，尚不能称为稳定身份。
- 原生记忆门控对真实正前缀的召回约为 `86.6–88.6%`，四组接近，因此不是组间崩溃的首要解释。
- 背景占绝大多数时，出生校准误差可以看起来很小，但事件召回仍接近零；不能只看总体校准分数。

## 代码审计发现的结构性风险

请亲自从 GitHub 精确提交核验以下判断，不要直接接受：

1. 训练时会建立教师轨迹；预测出生只有在查询编号恰好等于教师轨迹当前查询时，才继承真实事件身份。
2. 其他预测轨迹保留“无真实身份”，其归属监督被设为背景、类别监督被忽略，也不进入真实事件的终点风险。
3. 推理时所有轨迹都是预测轨迹，因此这里可能存在关键的训练—推理轨迹标签错配。
4. 出生前时序历史和删失风险集合在每个批次内重新建立；同一视频跨越多个批次，名义上的六十四前缀窗口会在批次边界截断。
5. 训练时继承的原生记忆门控使用真实前景标记，而评估时使用学习门控。严格重放表明它不是当前组间差异的首因，但它仍可能破坏“训练与推理同一状态分布”的主张。
6. 当前“取消”复用了活动归属的背景状态，未必等价于具有明确语义和真实监督的取消事件。

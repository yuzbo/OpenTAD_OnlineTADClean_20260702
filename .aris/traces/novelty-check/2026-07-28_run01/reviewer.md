# Independent novelty review

The configured GPT-4o, Claude, Gemini, and MiniMax review interfaces were tried.
They were unavailable in this environment: missing API credentials for GPT-4o,
Gemini, and MiniMax, and a non-JSON Claude CLI failure.  These failures are
retained as a limitation; no cross-model consensus is claimed.

A fresh zero-history default reviewer then received only the five claim
definitions and the nearest-work summaries.

## Verdict

- C1–C4 overlap strongly with known primitives.
- C2 is principally a correct online protocol/application of survival
  likelihood, not new censoring theory.
- C5 is engineering and reproducibility unless supported by formal semantics;
  it is not a standalone model innovation.
- C4 is the strongest standalone candidate only if gradients and downstream
  state changes truly pass through birth, ownership, false birth,
  cancellation, and rebirth rather than merely reweighting a loss.
- The only plausible central novelty is the C1+C2+C3+C4 task-specific
  composition as one event process for strict-causal On-TAL.

## Mandatory proof burden

- Exact N/R/T/H/TH isolation, followed by component-level removal inside C1–C4.
- Same-class overlap and near-boundary stress strata.
- First-birth precision/recall/delay and calibration.
- End timing, right-censored calibration, false termination, and unresolved
  track rate.
- Owner swaps, ID switches, fragmentation, false cancellation, duplicate
  rebirth, and reacquisition success.
- Oracle-only, predicted-only, mixed-track, and detached-state unroll controls.
- Train/inference lifecycle gap, memory, latency, and throughput.
- Multiple seeds only after the registered seed-52 pilot gate passes.

## Kill criteria

- Any future frame, true duration, complete-video timing, offline EOS, or GT
  inference leakage.
- Lifecycle duplicates, non-positive intervals, silent capacity eviction, or
  unexplained ledger mutation.
- C4 removal has negligible effect on error recovery/train-inference gap.
- C3 has no stable improvement on simultaneous same-class identity metrics.
- Ordinary duration-free BCE matches H/TH on end calibration and closure.
- Composite gains disappear after controlling parameters, training budget, or
  stronger relevant baselines.
